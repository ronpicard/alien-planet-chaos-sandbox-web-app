# Alien Planet Chaos Sandbox

Interactive canvas sandbox — click to unleash black holes, suns, lightning, tornadoes, and tidal waves on a tiny alien world.

## Setup

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

## Scripts

- `npm run dev` — local development server
- `npm run build` — production build to `dist/`
- `npm run preview` — preview the production build
- `npm run lint` — run oxlint

## Controls

- **Tools** `1`–`5` — black hole, sun, lightning, tornado, tidal wave
- **A** — toggle auto-spawn
- **Arrow keys** — set gravity direction
- **Hold T / R** — rotate gravity
- Click the canvas to place the selected tool
